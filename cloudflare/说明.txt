OAO 云端 AI 架构（智谱 GLM-4.7-Flash）
=====================================

  GitHub Pages（OAO.html 静态前端）
        │  HTTPS，无 API Key
        ▼
  Cloudflare Worker（oao-ai）
        │  /glm/chat  /glm/health
        │  ZHIPU_API_KEY 仅存 Worker Secrets
        ▼
  智谱开放平台 open.bigmodel.cn
        模型: glm-4.7-flash

本地开发（可选，不影响外网用户）
--------------------------------
  双击「打开OAO.bat」→ 仍可使用本机 AnythingLLM / Ollama
  外网访问 GitHub Pages 时自动走 Worker → 智谱，无需本机开机

部署 Worker（首次或更新代码后）
--------------------------------
  1. 进入 cloudflare 目录
  2. 复制 wrangler.toml.example → wrangler.toml，填写 account_id
  3. 双击「部署智谱Worker.bat」
     - 浏览器登录 Cloudflare（wrangler login）
     - 粘贴智谱 API Key（wrangler secret put ZHIPU_API_KEY）
     - 自动 wrangler deploy

----

  → {"ok":true,"model":"glm-4.7-flash",...}

  GitHub Pages 打开 OAO.html → AI 侧栏对话 → 应正常回复

安全
----
  - 勿将 ZHIPU_API_KEY 写入 OAO.html、local-config.js 或 git
  - git-token.txt / tunnel-token.txt 已在 .gitignore
  - 若 Key 曾误提交，请在智谱控制台轮换 Key 并 revoke 旧 Key
