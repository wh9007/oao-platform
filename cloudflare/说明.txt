OAO 云端 AI 架构（智谱 GLM-4.7-Flash）
=====================================

  GitHub Pages（OAO.html 静态前端）
        │  HTTPS，无 API Key
        ▼
  Cloudflare Worker（oao-ai）
        │  /glm/chat  /glm/health
        │  ZHIPU_API_KEY 仅存 Worker Secrets
        ▼
  智谱开放平台 open.bigmodel.cn
        模型: glm-4.7-flash

本地开发（可选，不影响外网用户）
--------------------------------
  双击「本地测试OAO.bat」→ 使用 Node.js 静态服务器 + 本机 AnythingLLM / Ollama
  外网访问 GitHub Pages 时默认走 Worker → Tunnel → 本机 AnythingLLM / Ollama
  如需不依赖本机，可在 local-config.js 或前端配置设置 OAO_FORCE_GLM = true

部署 Worker（首次或更新代码后）
--------------------------------
  方式一（推荐）：双击「一键上传GitHub.bat」
    - 若本次提交包含 cloudflare/ 变更，上传成功后自动运行 deploy-worker-quick.ps1

  方式二（手动）：
    1. 进入 cloudflare 目录
    2. 复制 wrangler.toml.example → wrangler.toml，填写 account_id
    3. 首次运行 deploy-worker.ps1（会登录并设置 ZHIPU_API_KEY）
    4. 日常更新运行 deploy-worker-quick.ps1

安全
----
  - 勿将 ZHIPU_API_KEY 写入 OAO.html、local-config.js 或 git
  - git-token.txt / tunnel-token.txt 已在 .gitignore
  - 若 Key 曾误提交，请在智谱控制台轮换 Key 并 revoke 旧 Key
