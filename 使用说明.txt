  OAO 网站 — 使用说明
═══════════════════════════════════════════════════

【正式网站】
  https://wh9007.github.io/oao-platform/

【日常只需 3 个脚本】

  ① 打开OAO.bat          本地功能测试
  ② 启动远程AI.bat       外网远程访问本机 AI（合并版，每次运行即可）
  ③ 一键上传GitHub.bat   版本更新 / 发布到 GitHub Pages

  需要外网访问本机 AI 时：打开 AnythingLLM + 双击「启动远程AI.bat」，保持窗口不关
  首次运行会自动配置 Worker；高级菜单用 OAO服务器.bat menu
  上传后等约 2 分钟，正式站 Ctrl+F5 强制刷新。


───────────────────────────────────────────────────
一、三个主脚本说明
───────────────────────────────────────────────────

  【1. 打开OAO.bat — 本地测试】
    · 启动 http://127.0.0.1:8777/OAO.html
    · 检测 Ollama / AnythingLLM 是否就绪
    · 用于：AI 对话、小O会议、OAO翻译 功能验证
    · 不启动 Tunnel，不影响外网

  【2. 启动远程AI.bat — 远程 AI 一键启动（推荐）】
    · 每次需要外网访问时双击运行，自动完成：
        检查 AnythingLLM / Ollama
        检查 DNS 与 V2Ray 提示
        首次自动配置 Worker
        启动 Cloudflare Tunnel
    · 须保持本窗口打开，直到日志出现 Registered tunnel connection
    · 外网用户访问：https://wh9007.github.io/oao-platform/OAO.html
    · V2Ray 用户：先运行 V2Ray与Tunnel共存.bat 或暂时关闭 V2Ray
    · 检测连通：OAO服务器.bat check
    · 高级菜单：OAO服务器.bat menu

  【3. 一键上传GitHub.bat — 版本更新】
    · 自动 commit + push 到 wh9007/oao-platform
    · 首次需配置 git-token.txt（GitHub Token，repo 权限）
    · 日志：upload-log.txt

  ※ 旧版分散脚本已删除，统一使用上述 3 个入口 + scripts\ 内部文件

───────────────────────────────────────────────────
三、AI 架构（本地 + 云端）
───────────────────────────────────────────────────

  默认：AnythingLLM + Ollama 优先；Tunnel 离线时智谱 GLM 备援

  【AnythingLLM 知识库 — 必做】
    1. 安装 AnythingLLM 并启动（http://127.0.0.1:3001）
    2. 创建工作区「OAOeth」，绑定 Ollama 模型 qwen2.5:7b
    3. 工作区聊天设置 → 聊天模式选「查询 Query」（知识库检索；勿用 Agent）
    4. 填写 OAO_ANYTHINGLLM_API_KEY（AnythingLLM 设置 → API Keys）
    5. 登录 OAO 后点击 AI 区「+」上传文件/文本到知识库
    6. 对话默认从 OAOeth 工作区检索回答

  本地测试：打开OAO.bat + 本机 Ollama + AnythingLLM
  外网连本机：OAO服务器.bat 选项 1 + Worker 配置 LLM_ORIGIN / OLLAMA_ORIGIN
  智谱备援：OAO服务器.bat 选项 5 或 cloudflare\部署智谱Worker.bat


───────────────────────────────────────────────────
四、OAO翻译 / 小O会议
───────────────────────────────────────────────────

  · 浏览器模式默认可用（Chrome / Edge + 麦克风）
  · 分享观看需 OAO服务器 选项 2 或 1（:3011 中继）
  · 会议纪要优先 AnythingLLM + 本地 Ollama；失败时智谱备援


───────────────────────────────────────────────────
五、常见问题
───────────────────────────────────────────────────

  Q：外网 AI 无响应？
  A：OAO服务器.bat 选 [1]；确认 Tunnel Token 与 Worker 变量；控制台 OAO_Diagnostic.testRemoteTunnel()

  Q：本地 AI 显示 Ollama？
  A：正常。请 ollama pull qwen2.5 并启动 AnythingLLM oaoeth 工作区。

  Q：上传失败？
  A：查看 upload-log.txt；重新生成 GitHub Token（repo 权限）。
