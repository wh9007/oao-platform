  OAO 网站 — 使用说明
═══════════════════════════════════════════════════

【正式网站】
  https://wh9007.github.io/oao-platform/

【日常只需 3 个脚本】

  ① 打开OAO.bat          本地功能测试
  ② 启动远程AI.bat       外网远程访问本机 AI（合并版，每次运行即可）
  ③ 一键上传GitHub.bat   版本更新 / 发布到 GitHub Pages

  需要外网访问本机 AI 时：打开 AnythingLLM + 双击「启动远程AI.bat」，保持窗口不关
  首次运行会自动配置 Worker
  高级菜单：启动远程AI.bat menu
  连通检测：启动远程AI.bat check
  V2Ray 共存：启动远程AI.bat v2ray（或 V2Ray与Tunnel共存.bat）
  上传后等约 2 分钟，正式站 Ctrl+F5 强制刷新。

  ※ OAO服务器.bat 仍可用，内部已转发到「启动远程AI.bat」


───────────────────────────────────────────────────
一、三个主脚本说明
───────────────────────────────────────────────────

  【1. 打开OAO.bat — 本地测试】
    · 启动 http://127.0.0.1:8777/OAO.html
    · 检测 Ollama / AnythingLLM 是否就绪
    · 用于：AI 对话、小O会议、OAO翻译 功能验证
    · 不启动 Tunnel，不影响外网

  【2. 启动远程AI.bat — 远程 AI 一键启动（推荐）】
    · 每次需要外网访问时双击运行，自动完成：
        检查 AnythingLLM / Ollama
        检查 DNS 与 V2Ray 提示
        首次自动配置 Worker
        启动 Cloudflare Tunnel
    · 可选参数：
        menu   — 高级菜单（原 OAO服务器 菜单）
        check  — 仅检测连通性
        v2ray  — V2Ray 与 Tunnel 共存修复
    · 须保持本窗口打开，直到日志出现 Registered tunnel connection
    · 外网用户访问：https://wh9007.github.io/oao-platform/OAO.html

  【3. 一键上传GitHub.bat — 版本更新】
    · 自动 commit + push 到 wh9007/oao-platform
    · 首次需配置 git-token.txt（GitHub Token，repo 权限）
    · 日志：upload-log.txt


───────────────────────────────────────────────────
二、项目结构
───────────────────────────────────────────────────

  【网站核心】
    OAO.html               主页面
    index.html             跳转 OAO.html
    assets/css/            样式
    oao-meeting-signal.js  小O会议信令
    oao-translate/embed/   OAO翻译（浏览器模式）

  【内部脚本（勿删）】
    scripts/lib.cmd        公共函数库
    scripts/*.ps1          启动/上传逻辑
    do-upload.ps1          上传核心（由 upload-github.ps1 调用）
    cloudflare/            Worker + Tunnel 配置

  【勿分享 / 勿上传】
    git-token.txt
    cloudflare\tunnel-token.txt
    local-config.js


───────────────────────────────────────────────────
三、小O会议 · 语音识别
───────────────────────────────────────────────────

  · 转写区上方可设置「识别灵敏度」
    标准 — 单人近距离
    高   — 推荐，多人同麦克风
    最高 — 多人近距离（关闭降噪/回声消除，增强弱声）
  · 「多人声纹识别」可区分发言人 A/B/C，支持手动改名
  · 建议使用 Chrome / Edge，并将系统麦克风音量调高


───────────────────────────────────────────────────
四、AI 架构（本地 + 云端）
───────────────────────────────────────────────────

  默认：AnythingLLM + Ollama 优先；Tunnel 离线时智谱 GLM 备援

  本地测试：打开OAO.bat + 本机 Ollama + AnythingLLM
  外网连本机：启动远程AI.bat + Worker 配置 LLM_ORIGIN / OLLAMA_ORIGIN
  智谱备援：cloudflare\部署智谱Worker.bat


───────────────────────────────────────────────────
五、常见问题
───────────────────────────────────────────────────

  Q：旁边的人说话识别不到？
  A：小O会议 → 识别灵敏度选「最高」；调高系统麦克风；两人尽量靠近麦克风

  Q：外网 AI 无响应？
  A：启动远程AI.bat check；确认 Tunnel Token 与 Worker 变量

  Q：上传失败？
  A：查看 upload-log.txt；重新生成 GitHub Token（repo 权限）。
