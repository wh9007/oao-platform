  OAO 网站 — 使用说明
═══════════════════════════════════════════════════

【正式网站】
  OAO.ETH  →  https://oao.eth.limo
  GitHub Pages →  https://wh9007.github.io/oao-platform/

【日常只需 3 个脚本】

  ① 本地测试OAO.bat       本地功能测试
  ② OAO服务器.bat         外网远程访问本机 AI
  ③ 一键上传GitHub.bat    版本更新 / 发布到 GitHub Pages

  需要外网访问本机 AI 时：打开 AnythingLLM + 双击「OAO服务器.bat」，保持窗口不关
  首次运行会自动配置 Worker
  高级菜单：OAO服务器.bat menu
  连通检测：OAO服务器.bat check
  V2Ray 共存：OAO服务器.bat v2ray
  上传后等约 2 分钟，正式站 Ctrl+F5 强制刷新。
  若上传包含 cloudflare/ 变更，会自动部署 Worker。


───────────────────────────────────────────────────
一、三个主脚本说明
───────────────────────────────────────────────────

  【1. 本地测试OAO.bat — 本地测试】
    · 使用 Node.js 内置静态服务器，不再依赖 Python
    · 启动 http://127.0.0.1:8777/OAO.html
    · 检测 Ollama / AnythingLLM 是否就绪
    · 用于：AI 对话、小O会议、OAO翻译 功能验证
    · 不启动 Tunnel / Docker，不影响外网

  【2. OAO服务器.bat — 远程 AI 一键启动】
    · 每次需要外网访问时双击运行，自动完成：
        Docker + SearXNG 联网搜索
        检查 AnythingLLM / Ollama
        检查 DNS 与 V2Ray 提示
        首次自动配置 Worker
        启动 Cloudflare Tunnel
    · 可选参数：
        menu   — 高级菜单（Worker 部署、连通检测等）
        check  — 仅检测连通性
        v2ray  — V2Ray 与 Tunnel 共存修复说明
    · 须保持本窗口打开，直到日志出现 Registered tunnel connection
    · 外网用户访问：https://wh9007.github.io/oao-platform/OAO.html

  【3. 一键上传GitHub.bat — 版本更新】
    · 自动 commit + push 到 wh9007/oao-platform
    · 首次需配置 git-token.txt（GitHub Token，repo 权限）
    · 若本次提交包含 cloudflare/ 文件，上传成功后自动部署 Worker
    · 日志：upload-log.txt

  【勿分享 / 勿上传】
    git-token.txt
    cloudflare\tunnel-token.txt
    local-config.js


───────────────────────────────────────────────────
三、小O会议 · 语音识别
───────────────────────────────────────────────────

  · 转写区上方可设置「识别灵敏度」
    标准 — 单人近距离
    高   — 推荐，多人同麦克风
    最高 — 多人近距离（关闭降噪/回声消除，增强弱声）
  · 「多人声纹识别」可区分发言人 A/B/C，支持手动改名
  · 建议使用 Chrome / Edge，并将系统麦克风音量调高


───────────────────────────────────────────────────
四、AI 架构（本地 + 云端）
───────────────────────────────────────────────────

  默认：AnythingLLM + Ollama（本地预览与外网 Tunnel 均优先本机 AI）
  可选：设置 OAO_FORCE_GLM = true 后，外网可改用 Cloudflare Worker → 智谱 GLM

  想强制本机 AI：local-config.js 打开 window.OAO_FORCE_LOCAL_AI = true
  外网连本机：OAO服务器.bat + Worker 配置 LLM_ORIGIN / OLLAMA_ORIGIN
  Worker 首次配置：cloudflare\deploy-worker.ps1（设置 ZHIPU_API_KEY）
  Worker 日常更新：cloudflare\deploy-worker-quick.ps1


───────────────────────────────────────────────────
五、常见问题
───────────────────────────────────────────────────

  Q：旁边的人说话识别不到？
  A：小O会议 → 识别灵敏度选「最高」；调高系统麦克风；两人尽量靠近麦克风

  Q：外网 AI 无响应？
  A：先打开 https://oao-ai.wh529007.workers.dev/glm/health
     正常应为 ok:true；若 false 或提示 zhipu_not_configured，运行
     cloudflare\deploy-worker.ps1 设置 ZHIPU_API_KEY。
     若使用本机 AI，再运行 OAO服务器.bat check 检查 Tunnel。

  Q：上传失败？
  A：查看 upload-log.txt；重新生成 GitHub Token（repo 权限）。
